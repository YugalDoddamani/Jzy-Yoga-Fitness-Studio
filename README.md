# J'zy Yoga & Fitness Studio

A mobile-first, single-page landing page concept for J'zy Yoga & Fitness Studio in Caranzalem, Panaji, Goa. Built with plain HTML, CSS and JavaScript for lightweight static hosting (including Cloudflare Pages).

## Preview locally
Open `index.html` in a browser, or run a local static server from this folder.

## Before sharing with the studio
- [ ] Replace `REPLACE_WITH_JASMINE_NUMBER` in `script.js` with Jasmine's WhatsApp number in international digits-only format (India: 91 + mobile number).
- [ ] Confirm the exact studio address and nearby landmark. The church landmark currently shown in the page is marked for confirmation.
- [ ] Verify the programs and descriptions with Jasmine. The copy is intentionally framed as enquiry prompts, not confirmed class schedules or medical claims.
- [ ] Replace the stock photography with approved studio/class photos when available.
- [ ] Confirm the current review rating before adding a rating badge. No rating number is asserted on this draft.
- [ ] Test WhatsApp links, Google Maps directions and the mobile navigation on a phone.
- [ ] Ensure image licensing and any required image attribution are handled before production.

## Design intent
Warm ivory backgrounds, deep botanical green, muted terracotta and soft sage; editorial serif headlines; generous spacing; two clear pathways for women and kids; repeated WhatsApp enquiry actions; sticky mobile enquiry bar; accessible navigation and reduced-motion support.

No build step or framework is required.
